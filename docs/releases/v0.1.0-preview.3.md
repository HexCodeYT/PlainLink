# PlainLink v0.1.0 Preview 3

PlainLink v0.1.0 Preview 3 is an ad-hoc-signed, unnotarized technical preview for macOS testers.

## Highlights

- Native Swift/AppKit menu bar app backed by the Rust cleaning engine.
- Automatic clipboard cleaning with inspect and restore support.
- Conservative rules that preserve unknown parameters by default.
- Fixture-backed rule verification.
- HN-ready installation, Gatekeeper, privacy, and technical-preview guidance.
- Multi-resolution app icon verification during packaging.

## Artifact

This preview build is ad-hoc signed and not notarized. macOS Gatekeeper will warn before opening the app. Follow the exact first-launch steps in the repository README.

Expected artifact names:

```text
PlainLink-0.1.0-preview.3-macos-arm64.zip
PlainLink-0.1.0-preview.3-macos-arm64.zip.sha256
```

## Tester Ask

Please report URLs PlainLink changes incorrectly or should clean but does not. Include the copied URL, PlainLink's output, and the expected clean URL.

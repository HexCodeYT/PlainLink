# PlainLink v0.1.0 Preview 5

PlainLink v0.1.0 Preview 5 is an ad-hoc-signed, unnotarized technical preview for Apple silicon Macs running macOS 11 or later.

## Fixes

- Corrects the Swift menu-bar executable's Mach-O minimum deployment target from macOS 27.0 to macOS 11.0.
- Adds a packaging check that verifies both bundled executables match `LSMinimumSystemVersion` before an artifact is created.
- Retains Preview 4's automatic watcher refresh, schemeless-link cleaning, and pause-state behavior.

## Installation

Because this preview is not Developer ID-signed or notarized, macOS may incorrectly report that the downloaded app is damaged. Follow the exact quarantine-removal instructions in the repository README.

Expected artifact names:

```text
PlainLink-0.1.0-preview.5-macos-arm64.zip
PlainLink-0.1.0-preview.5-macos-arm64.zip.sha256
```

## Tester Ask

If you are running macOS 11 through macOS 26, please confirm that the menu-bar app launches and starts cleaning after installation.

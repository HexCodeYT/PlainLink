# PlainLink v0.1.0 Preview 4

PlainLink v0.1.0 Preview 4 is an ad-hoc-signed, unnotarized technical preview for macOS testers.

## Fixes

- Refreshes the installed clipboard watcher from the app's bundled engine on every non-paused launch.
- Prevents drag-and-drop upgrades from continuing to run an older installed CLI.
- Preserves an explicit **Pause Cleaning** choice across later app launches.
- Includes schemeless-link cleaning for inputs such as `youtube.com/...` and `amazon.com.au/...`.
- Starts cleaning automatically for new installations.

## Installation

Because this preview is not Developer ID-signed or notarized, macOS may incorrectly report that the downloaded app is damaged. Follow the exact quarantine-removal instructions in the repository README.

Expected artifact names:

```text
PlainLink-0.1.0-preview.4-macos-arm64.zip
PlainLink-0.1.0-preview.4-macos-arm64.zip.sha256
```

## Tester Ask

After replacing an older preview, launch PlainLink normally and confirm that both full and schemeless copied URLs are cleaned without manually running the embedded CLI installer.
